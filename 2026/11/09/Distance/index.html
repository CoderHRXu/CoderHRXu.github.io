iOS计算点到直线的距离以及与垂足的交点

1.问题描述

假设有一点坐标P（x0,y0）,有一线段AB，A坐标（x1，y1），B坐标（x2，y2），求P点到AB线段或所在直线的距离d以及P点在直线上的垂足C（x，y）。

2.分析

首先需要将A，B两点坐标转换为直线方程的一般式Ax+By+C = 0，在根据距离公式计算

下面是推算过程

参数计算：
A=y2-y1；
B=x1-x2；
C=x2y1-x1y2;
1.点到直线的距离公式：
d= ( Ax0 + By0 + C ) / sqrt ( AA + BB );
2.垂足C（x，y）计算公式：
x = ( BBx0 - ABy0 - AC ) / ( AA + BB );
y = ( -ABx0 + AAy0 – BC ) / ( AA + BB );
